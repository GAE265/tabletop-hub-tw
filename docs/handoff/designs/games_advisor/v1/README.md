## 本輪提議的方向

- **友善的桌遊聚會感**：首頁用少量骰子、米寶、板塊裝飾；開始對話後，讓文字與卡片成為主角。
- **沿用現有綠色探索**：以目前 `frontend/lib/app/theme/app_colors.dart` 的 seed `#2E7D6B` 為生成提示基底，搭配米白、淺薄荷與深綠文字；這是本輪提案，並非已定案的品牌色票。
- **清楚的對話與閱讀層次**：玩家用深綠泡泡，Agent 用淺色區塊；卡片將名稱、基本資訊、理由、心得片段分層，英文心得保留「英文」標示。
- **統一操作區**：三張保留「開始新對話」、輸入框、500 字計數與鍵盤提示；規則問答維持停用。

可以先討論插畫份量、綠色與米白的比例、標題字重，以及長心得是否好讀，再由永傑決定正式頁面的細節。

## 與功能交接的關係

行為與操作以 [ticket 09 交接說明](../../../games_advisor.md) 為準。這組稿件保留三個原有範例、追問內容、兩款桌遊資料及原有心得片段，移除開發身分列與 DEBUG 標記；沒有新增收藏、篩選、購買、訂位或歷史對話等操作。

本輪尚未繪製手機版、載入中、對話失效、暫時無法回應及放寬條件的畫面，正式 UI 製作時仍需依交接說明涵蓋這些狀態。字型、間距、元件尺寸與 RWD 尚待正式設計確認。

## 生成與檢查

- 工具：內建 `image_gen`，以原截圖作為內容參考，並以第一張生成稿統一後續視覺；未使用 CLI 或專案模型金鑰。
- 提示詞：[prompts.md](prompts.md)，保留三張完整提示與第三張的圖示／泡泡一致性修正。
- 成品：三張 PNG，均為 1122 × 1402 px。
- 已逐張視覺核對主要繁中文字、範例、追問、卡片數據與心得內容；原截圖未變，新圖複製後的 SHA-256 與生成檔一致。
- 文件範圍：本資料夾的設計圖與說明，以及交接文件的設計稿索引；Flutter、主題與票券狀態維持原樣。
