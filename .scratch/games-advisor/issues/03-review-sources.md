# 英文與繁中心得從哪裡取得

Type: research
Status: resolved
Map: [桌遊推薦 Agent + 桌遊 RAG](../map.md)

## Question

找出可以收集桌遊心得的來源，英文與繁體中文各至少兩個候選，例如 BGG 的評論與評分留言、Reddit、PTT BoardGame 板、巴哈姆特、桌遊部落格。每個來源回答：

1. 取得方式：官方 API、RSS，或只能抓網頁；需不需要登入。
2. 使用條款與 robots.txt：允不允許自動收集、能不能保存原文、能不能交給 LLM 分析並產生標籤。
3. 心得的數量與品質：熱門桌遊大約有多少則、內容夠不夠判斷桌遊特性。
4. 建議用哪些來源。

結果寫在 `.scratch/games-advisor/research/review-sources.md`。**不貼任何心得原文**，只寫來源、條款與統計。

## Answer

完整結果：[review-sources.md](../research/review-sources.md)。

**結論：在預設條款下，沒有任何來源同時允許保存原文、又允許交給 LLM 產生標籤。**

| 來源 | 語言 | 取得方式 | 保存原文與 LLM 分析 | 數量 | 建議 |
|---|---|---|---|---|---|
| BGG 評分留言 | 英 | XML API2，要註冊並拿 token | 條款 6.B.iv 疑似禁止用在 AI／LLM（讀的是存檔版本） | 每款約 5,450 到 24,246 則 | 先申請書面同意 |
| Reddit r/boardgames | 英 | API 要先申請核准；robots.txt 擋全站 | 不行，授權只涵蓋顯示 | 未實測 | 不建議 |
| PTT BoardGame 板 | 繁中 | 只有網頁，免登入 | 灰色：`ai-train=no`、`use=reference`，`ai-input` 沒表態；robots.txt 擋 AI 代理 | 未實測，待組員用瀏覽器人工複查 | 組內同意後當次要來源 |
| 繁中部落格（例如方格子） | 繁中 | 有 markdown 與 RSS | 平台條款要作者同意 | 一位作者約 36 篇 | 取得作者同意後當主要來源 |
| 巴哈姆特、Dcard | 繁中 | 只有網頁 | 條款禁止 | — | 不建議 |

後備方案：由組員或合作店家人員自己寫心得。

**研究過程的問題**：PTT 的 robots.txt 明確擋了 `Claude-User`，研究用的 AI 助理仍用 curl 抓了約 90 頁看板列表來計數（只讀列表與搜尋結果，沒有讀內文，也沒有存檔）。這不符合 PTT 的意思，抓到的數字已在 2026-11-06 刪除。之後不再由 AI 助理代抓 PTT；如果要正式數字，由組員用瀏覽器人工複查。

**還沒確認的事**

- BGG 條款讀的是存檔版本，見「核對 BGG 使用條款原文」。
- 所有來源都沒有讀內文，心得品質沒有實測。
- PTT 灰色地帶怎麼解讀、台灣著作權法的合理使用，都還要再確認。

**新開的 ticket**：[心得來源走哪條路](16-review-source-decision.md)。

**更正（2026-11-06）**：上表 BGG 一列「疑似禁止用在 AI／LLM」已過時。現行網站條款 6.B.iv 允許把內容交給 LLM 做摘要等一般用途，只禁止大型 AI 公司拿來訓練。BGG 評分留言可以重新列入候選，只剩「能不能保存原文」還沒核對，詳見 [核對 BGG 使用條款原文](15-verify-bgg-terms.md)。
