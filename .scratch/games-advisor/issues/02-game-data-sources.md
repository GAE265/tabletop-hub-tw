# 桌遊基本資料從哪裡取得

Type: research
Status: resolved
Map: [桌遊推薦 Agent + 桌遊 RAG](../map.md)

## Question

比較公開可查、具公信力或使用廣泛的桌遊資料來源。至少包含 BoardGameGeek XML API2，另外找有繁體中文名稱的來源。每個來源回答：

1. 取得方式：API 或下載檔、要不要申請帳號或 token、速率限制。
2. 使用條款：能不能存進自己的資料庫、能不能用在公開 Demo、要不要標示來源。repo 是公開的，資料能不能放進 repo。
3. 可取得的欄位：人數（含建議人數）、遊戲時長、年齡、難度、類別與機制、說明文字、圖片、繁中名稱。
4. 建議用哪一個，或怎麼組合。

只用官方文件與使用條款等一手來源。結果寫在 `.scratch/games-advisor/research/game-data-sources.md`。

## Answer

完整結果：[game-data-sources.md](../research/game-data-sources.md)。

**BoardGameGeek XML API2**
- 取得方式：要申請 application，並使用 Bearer token；不帶 token 實測回 401。官方沒有公布速率限制，一次請求最多 20 個 ID。
- 使用條款：只限非商業用途，必須標示來源並放上「Powered by BGG」logo。網站條款疑似禁止把 BGG 資料用在 AI／LLM 系統，BGG 開發者 2026-10-13 公開說明即時查詢也算在內。**這條只從搜尋引擎索引間接讀到，還沒看過原文。**
- 欄位：最完整，包含難度（`averageweight`）與建議／最佳人數。
- 結論：條款確認之前，只放外部連結，不使用它的資料。

**Wikidata**
- 取得方式：SPARQL 免註冊，有查詢時間與同時查詢數的限制，要送出可辨識的 User-Agent。
- 使用條款：CC0，可以存進資料庫、用在 Demo、交給 LLM 分析。
- 欄位：4,757 款有 BGG ID。人數只有 47% 有值，時長 17%，年齡 21%，沒有難度；有 `zh-tw` 名稱的只有 29 款。
- 結論：可以當條件欄位的基底，但缺漏很多。

**台灣代理商官方商品頁**
- 有繁中名稱、人數、時間、年齡，但沒有 API，版權全部保留。
- 結論：只能用來人工核對繁中名稱與條件欄位。

**繁中名稱**：BGG 的別名沒有語言標記，版本語言只標「Chinese」不分繁簡，無法可靠地挑出繁中名稱。

**建議**：用 Wikidata 加上人工對照代理商頁；難度等偏好欄位由我們自己定義。BGG 要等條款原文確認後再決定，需要時可以申請非商業用途的書面同意。

**新開的 ticket**：[核對 BGG 使用條款原文](15-verify-bgg-terms.md)，「收錄哪些桌遊、存哪些欄位」要等這張完成。

**更正（2026-11-06）**：上面 BGG「條款疑似禁止用在 AI／LLM」的說法已過時。現行網站條款 6.B.iv 允許把內容交給 LLM 做摘要、搜尋、回答問題等一般用途，只禁止大型 AI 公司拿來訓練。研究讀到的是 2026-10-18 存檔的舊版。BGG 可以重新列入候選，詳見 [核對 BGG 使用條款原文](15-verify-bgg-terms.md)。
