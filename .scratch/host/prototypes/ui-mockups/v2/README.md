# AI 語音主持參考設計稿 v2

這四張圖供永傑預先了解《血與刃的白薔薇》語音主持會怎麼呈現在畫面上，尚未定案。功能還在決策階段，行為以之後的 spec 與交接說明為準。

第一組沿用 App 現有主題，這一組依照同桌玩家使用語音主持的需求配色、排版，並多畫一張筆電版。兩組對應畫面的元件與文字相同。[第一組設計稿（v1）](../v1/README.md)

## 第 3 張的兩個差別

**接話方式**決定玩家怎麼開口。切到「按住說話」後，上方的模式標籤跟著改，畫面也多了一顆圓形麥克風鍵。玩家按住時主持人立刻停，放開後主持人才回答。

**主持暫停中**表示流程停在目前階段。畫面多了「主持暫停中」橫幅，底部的「暫停」鍵換成「繼續」。暫停時也可以問規則。

## 這一輪的視覺方向

提案採用深墨藍底、暖白大字和杏色按鍵，讓同桌玩家隔著桌子也能找到目前階段。查規則時看聲波下方的文字，暫停時看酒紅色橫幅。正式配色、字級與間距由永傑決定。

| 使用需求 | 圖上怎麼處理 |
|---|---|
| 聲音帶流程，畫面協助玩家跟上 | 回合和目前階段擺在一起，語音指令另外列在操作鍵旁。 |
| 5 到 10 人圍桌共看 | 目前階段用粗體大字和實心圓標出，已完成的階段有勾，還沒到的階段用空心圓。 |
| 語音操作為主，伸手也要按得到 | 手機把三顆流程鍵排在底部，主要按鍵填上杏色。 |
| 主持時螢幕常亮 | 大面積用深色，保留亮字和少量亮色按鍵。 |
| 分辨主持、暫停、查規則與按住說話 | 主持中看進度，暫停看橫幅，查規則看聲波旁的文字，按住說話則看圓形麥克風鍵。 |
| 手機可用，也要用筆電展示 | 手機由上往下讀，筆電把進度放左邊、指令和按鍵放右邊。 |
| 遊戲發生在夜晚，氣氛懸疑 | 以墨藍底色帶出夜色，酒紅只用在暫停提示。 |
| 主持人有男聲與女聲，人設待定 | 稿中用抽象聲波代表主持人，保留日後決定人設的空間。 |

## 哪些內容不在圖上

### 已決定不做的項目

展示時直接使用主持頁面，不另做展示頁。查到的規則片段與頁碼、整局記憶的內容，以及每一步的處理紀錄都不顯示。

### 這一輪省略的狀態與版面

回到頁面、螢幕常亮被拒、被別的裝置取代、麥克風被拒絕、聲音待啟用、重新連線中、連不上、沒有權限、人數不對，這九種情況都還沒畫。也省略了主持結束後的「接著主持／重新開始」、開場到夜晚的進度，以及平板版面。

### 還沒決定的事

頁面名稱、從 App 的哪裡進入、手機要不要顯示底部導覽列，都還沒定。是否顯示主持人和玩家的逐字稿、夜晚倒數要不要顯示數字，以及按「結束主持」要不要再確認，也留待決定。平板與桌機的排法仍在討論，第 4 張僅供比較。

### 已知瑕疵

逐張檢視成品，沒有發現錯字、簡體字、多字、漏字、缺少元件或文字難以辨讀的地方。
