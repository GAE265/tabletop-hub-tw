# 玩家怎麼和主持人說話

Type: grilling
Status: open
Blocked by: 01, 05, 07
Map: [AI 語音主持](../map.md)

## Question

全桌玩家共用桌上一台手機或平板的麥克風。玩家會邊玩邊聊天、說「嗯」，主持人不能每句都接話。依模型規格與立倫試聽的感受，決定：

1. 什麼時候主持人才聽：按住頁面上的按鍵才說話、說出喚醒詞（例如「主持人」）、或模型自動判斷。選型查核報告建議先用按鍵，待確認。已知這個設定只能在連線一開始決定，同一條連線不能中途在「按鍵」與「自動」之間切換。
2. 主持人正在說話時，玩家怎麼打斷：按鍵、開口，或兩種都可以。打斷後還沒說完的內容要不要補說。
3. 旁邊的聊天與附和聲怎麼處理。
4. 一台裝置認不出是誰在說話（從聲音認人已列為範圍外）。主持人需要知道「是幾號座位在問」嗎；需要的話怎麼知道。
5. 玩家用其他語言或台語說話時，主持人怎麼回應。
6. 麥克風沒有權限、收不到聲音、連線中斷時，頁面要顯示什麼。研究建議的狀態有：開始主持、麥克風被拒絕、聲音待啟用、頁面已暫停、重新啟用。
7. 手機瀏覽器要玩家先點一下才能出聲，所以一定要有「開始主持」這個動作。它放在哪、誰來點。
8. 螢幕鎖住或切到別的 App 之後，收音和播音不保證還能運作。要不要讓頁面保持螢幕常亮；真的被切走時怎麼處理。

## Comments

- 2026-11-19：「[Qwen 即時語音模型的官方規格](01-qwen-realtime-facts.md)」與「[Flutter Web 怎麼收音與即時播音](05-flutter-web-audio.md)」已結案。和這張有關的事實（細節在 [qwen-realtime-facts](../research/qwen-realtime-facts.md)、[flutter-web-audio](../research/flutter-web-audio.md)）：
  - 自動接話：官方建議用 `smart_turn_v2`，同時看聲音與語意，說可以減少附和聲與旁聊造成的回應與中斷。效果是廠商自己的說法，要看試聽。
  - 打斷：模型端取消回答後，已經送到裝置的聲音不會自動消失。前端要自己停播、清空待播內容，並丟掉之後才送到的舊回覆。實際多快停下來要實測。
  - 回音消除：瀏覽器可以要求打開，但不保證生效，也不保證桌上喇叭的聲音不會被收進去。
  - 模型有「只聽特定說話者」的功能，要先錄那個人的聲音，不能當成辨識四位玩家的方法。
  - 手機要 HTTPS 才能用麥克風。保持螢幕常亮的功能只在頁面看得見時有效，低電量時系統可能拒絕。
