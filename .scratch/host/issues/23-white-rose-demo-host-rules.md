# 白薔薇 demo 的主持規則：追加哪些、忽略哪些

## Question

《血與刃的白薔薇》是這次 demo 的桌遊（2026-11-20 需求變更）。主持人不必照規則書做到每一條：有些規則書沒有的事要加進來，有些規則書有的事刻意不管。這張把清單定下來。

為什麼現在要定：「選哪個 Agent 框架」與「寫 spec.md」都要等它。

- 每個階段開始時，後端交給主持人的規則要點有哪些（需求變更：主持人照規則說話，不再自由說）。規則要點的來源與格式在「[寫 spec.md](21-write-spec.md)」定。
- 主持人的規則摘要要寫哪些內容。「[主持人能查哪些資料、誰能開主持](13-host-tools-and-permissions.md)」沒有等這張（立倫決定撤回）；它先決定規則從哪裡查，內容再依這張的清單寫。
- 流程有哪些節點、整局記憶要記什麼（「[選哪個 Agent 框架、它負責什麼](10-agent-framework-choice.md)」）。

已經定案、當作起點的清單（沒有被需求變更推翻，要改請在這張明說）：

- 已追加（規則書沒有主持人，這些是我們加的）：
  - 開場唸人數、圓版格數、兩個陣營的獲勝門檻。
  - 開局準備用一段話帶過。
  - 夜晚兩步由主持人唸口令並倒數（睜眼互看 3 秒、敲桌子 10 秒）。
  - 放最後一顆水晶的回合，開始與翻牌後各提醒一句。
- 已忽略：
  - 魔法之書的效果不解釋，玩家自己讀。
  - 主持人不知道翻牌結果，不記獻祭區、死亡區的張數，不結算、不判勝負。
  - 不讀戰績（`matches`）的局與回合紀錄。
  - 不向玩家要陣營、手牌、水晶數字；不分析誰是哪個陣營。

決定：

1. 還要追加哪些主持規則。立倫先說想到的，再逐個階段對一遍（開局準備、夜晚、每個回合的三個階段、結束）。
2. 還要刻意忽略哪些規則。同樣逐個階段對一遍。
3. 上面「已忽略」的四項，為了 demo 要不要改。
4. 每個階段開始時，主持人一定要說到的規則要點是哪幾條（用自己的話寫，不抄規則書）。
5. 玩家問到被忽略的規則時，主持人怎麼回答。魔法之書已有固定的一句，其他的要不要比照。

規則書原文不進 repo（AGENTS.md §2 第 2 點）。Answer 只寫用自己的話寫的結論。新出現的用詞當場寫進 `GLOSSARY.md` 的提案區。

## Answer

2026-11-21 立倫決定。所有台詞都是用自己的話寫的草稿，定稿留到實作。

### 1. 主持人多做的事（剩三項）

規則書沒有主持人，這些是我們加的：

1. **開場**：只打招呼。**不唸人數、圓版格數、兩個陣營的獲勝門檻**（更正題目「已追加」第一項）。開主持時仍要填人數。
2. **開局準備**：照「[主持人在一局裡怎麼帶流程](08-host-flow-in-a-match.md)」第 2 節的那一段話，不補內容。
3. **夜晚兩步**：主持人唸口令並倒數（睜眼互看 3 秒、敲桌子 10 秒），不變。

拿掉的：

- **最後一個回合的兩句提醒都不做**（更正題目「已追加」第四項）。

提過、決定不做的：

- 開局準備補「這個人數用哪幾張角色牌」與「桌上放一張備用雙刃牌」。
- 每個回合開頭報「第 N 回合，圓版還剩 K 格」。
- 階段 3 結尾提醒「達到門檻就說某一方贏了，還沒有就說下一步」。
- 規則要點加一句「魔法之書有另外規定的，照書上的」。

### 2. 主持人刻意不管的事（共九項）

題目列的四項都不改：

1. 魔法之書的效果不解釋，玩家自己讀。
2. 不知道翻牌結果，不記獻祭區、死亡區的張數，不結算、不判勝負。
3. 不讀戰績（`matches`）的局與回合紀錄。
4. 不向玩家要陣營、手牌、水晶數字；不分析誰是哪個陣營。

再加五項：

5. 開場不先教整套規則，只在每個階段開始時說那個階段的規則要點。
6. 不計時、不催。只有夜晚的兩個倒數。
7. 不點名、不追蹤：不說換誰了，不記金幣在誰手上、誰還有水晶、誰出了牌。
8. 不主動糾正違規（亮牌、說出水晶數字、順序走錯）。被問才照規則回答。
9. 不給打法建議；結束後不提醒記戰績。

### 3. 每個階段的規則要點

規則要點只規定「要說到哪幾條」，字句由主持人自己組（定義在 `GLOSSARY.md`）。固定台詞才是整句照唸。

- **第 1 回合說完整版，第 2 回合起說簡短版。**
- 說「上一步」「繼續」，或被閒聊切斷後自動重講時，用那個回合該用的版本。例：第 2 回合階段 1 說「上一步」，回到第 1 回合階段 3，重講完整版。
- 不報第幾回合，不報圓版剩幾格。
- 魔法之書改了流程時（例如放水晶的人改成最後決定、這個回合不混洗），主持人不問放了幾號，照一般情況說。

標「簡」的是簡短版也要說到的。

**階段 1：傳金幣、放水晶**

1. 「簡」拿金幣的人，把金幣交給另一位還有水晶的玩家。給誰由他決定。
2. 大家可以討論、爭取或推掉金幣，但不能說出自己水晶的數字和效果。
3. 「簡」收到金幣的人把水晶放上圓版，照格子的順序放，數字朝上。
4. 「簡」照水晶的數字，做魔法之書上同一個編號的效果。

**階段 2：決定出牌**

1. 「簡」從放水晶的人開始，順時針輪流決定。
2. 「簡」每個人二選一：蓋一張牌在自己面前，或說「不出」。
3. 每個人只有一個機會。

**階段 3：翻牌結算**

1. 「簡」把所有蓋著的牌收在一起混洗，再全部翻開。
2. 沒有刃牌：幽魂移出遊戲，信者和司教放獻祭區，白薔薇放白薔薇區。
3. 有刃牌、沒有白薔薇：幽魂移出遊戲，信者和司教放死亡區。
4. 刃牌和白薔薇同時出現：血刃陣營立刻獲勝。

簡短版只留第 1 條，再加一句「照翻出來的牌結算」，三種結果不重講。

### 4. 被問到不管的事怎麼回答（固定台詞五句）

這五類不用查規則，直接回答。N、M 是這局的門檻，由人數查「[對照實體遊戲，補齊白薔薇規則裡讀不到的地方](15-white-rose-rule-gaps.md)」的表。

| 玩家問的事 | 主持人回答（草稿） |
|---|---|
| 魔法之書的效果，包含「效果一定要發動嗎」這種問法 | 「魔法之書的效果要看書上的說明，我不能為你解釋。」（已定，不變） |
| 現在誰贏、死亡區或獻祭區幾張了 | 「我看不到桌上的牌，請你們自己數。這局白薔薇陣營要獻祭 N 張花苞，血刃陣營要死亡區 M 張。」 |
| 誰是血刃、我該不該出牌 | 「這個要靠你們自己判斷，我只負責流程和規則。」 |
| 換誰了、金幣在誰那、誰還有水晶 | 「我看不到桌面，請直接問同桌的玩家。」 |
| 幫我記這一局、幫我算分 | 「我不會記戰績，請到戰績畫面輸入。」 |

門檻數字主持人不主動說，只在第二句與回答勝負規則時說。

### 5. 結束

- 玩家有說哪一方贏：恭喜那一方，再補一句符合遊戲調性的話。
- 玩家只說「結束了」：只說「這一局結束了。」
- **都不說「辛苦了」。**
- 圓版放滿的那個回合（回合數等於圓版格數）走完階段 3 之後說「下一步」：已經沒有下一個回合，當成「結束了」。主持人不主動提醒圓版放滿，也不判勝負。

### 6. 流程節點（給「選哪個 Agent 框架、它負責什麼」）

沒有新增節點：開場、開局準備、夜晚第一步、夜晚第二步、每個回合的階段 1、階段 2、階段 3、結束。

### 7. 規則摘要要答得出的主題（給「主持人能查哪些資料、誰能開主持」）

規則從哪裡查由那張決定。不管從哪裡查，主持人要答得出這五個主題：

1. 人數、陣營、各人數的角色牌組。開局準備不唸牌組，玩家開口問才回答。
2. 開局準備與夜晚。
3. 一個回合的三個階段。
4. 勝負與結束，用真的門檻。
5. 公開與私密資訊，加上規則書自己列的常見疑問（例如整桌都不出牌合不合法）。

魔法之書不放，一律回固定台詞。

### 8. 例句（草稿，7 人局）

立倫看過並改過的版本。定稿在實作時由立倫試聽。

| 開局準備 | 「先來準備。每個人拿自己的幽魂牌、信者牌和魔法之書，再抽一顆水晶，數字不要給別人看。角色牌洗好，每人發一張。金幣交給任意一位玩家。好了就說『下一步』。」 |
| 夜晚第一步 | 「天黑了，請所有人閉上眼睛。白薔薇、司教、雙刃、巨刃，請睜開眼睛，看看彼此。三、二、一，請閉上眼睛。」 |

| 階段 1 完整版 | 「現在是傳金幣、放水晶。拿金幣的人，把金幣交給另一位還有水晶的玩家，給誰由你決定。大家可以討論，但不能說出自己水晶的數字和效果。收到金幣的人，把水晶放上圓版，照格子的順序放，數字朝上，再照數字做魔法之書上同一個編號的效果。」 |
| 階段 1 簡短版 | 「傳金幣、放水晶。拿金幣的人把金幣交給另一位還有水晶的玩家，收到的人放水晶，照魔法之書的效果做。」 |
| 階段 2 完整版 | 「現在是出牌階段。從放水晶的人開始，順時針一個一個決定：蓋一張牌在自己面前，或是說『不出』。每個人只有一個機會。」 |

| 階段 3 完整版 | 「現在翻牌結算。把所有蓋著的牌收在一起混洗，再全部翻開。沒有刃牌：幽魂移出遊戲，信者和司教放獻祭區，白薔薇放白薔薇區。有刃牌、沒有白薔薇：幽魂移出遊戲，信者和司教放死亡區。刃牌和白薔薇同時出現：血刃陣營立刻獲勝。」 |
| 階段 3 簡短版 | 「翻牌結算。把蓋著的牌混洗後翻開，照翻出來的牌結算。」 |
