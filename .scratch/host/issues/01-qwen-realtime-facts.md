# Qwen 即時語音模型的官方規格

Type: research
Status: open
Map: [AI 語音主持](../map.md)

## Question

查清楚阿里雲 `Qwen-Audio-3.1-Realtime`（Flash 與 Plus）的官方規格，後面的決策都靠這些事實。選型查核報告（路徑見地圖 Notes）已有一部分數字，逐項回查一手來源，不直接照抄。

1. 連線方式：WebSocket 或 WebRTC、端點網址、區域（報告寫新加坡）、驗證方式。瀏覽器能不能直接連；有沒有短效憑證可以發給前端（AGENTS.md §5.3 規定前端不放任何秘密）。
2. 音訊：輸入與輸出的格式、取樣率、有沒有內建的回音消除或降噪。
3. 接話與插話：模型怎麼判斷玩家講完了（報告提到 `smart_turn_v2`）；能不能改成由應用程式控制（按住說話）；玩家插話時怎麼讓它停播。
4. 工具呼叫（function calling）：事件的先後順序、等工具結果時模型能不能先講話、一次能不能呼叫多個工具。
5. 連線限制：一次連線最長多久、保留多少歷史（報告寫 300 秒歷史音訊）、每次輸入的 token 上限、能不能用文字摘要接續上一段。
6. Flash 與 Plus 的差別：中文語氣、工具準確度、速度、價格各差多少。有沒有官方數字。
7. 語氣控制：能不能用指令指定語氣、語速、聲線；有哪些中文聲線。
8. 價格：音訊與文字的輸入、輸出單價；有沒有免費額度。
9. 資料處理：音訊會不會被保存、保存多久、會不會拿去訓練。
10. Python SDK 的名稱、版本、授權；有沒有同步寫法。

只用官方文件、官方價格頁、技術報告等一手來源，每項附連結、查核日期與版本。查不到的寫「查不到」，不要推測。
