# 主持人在一局裡怎麼帶流程

Type: grilling
Status: resolved
Blocked by: 04, 15
Map: [AI 語音主持](../map.md)

## Question

主持人以帶流程為主。首版只讀資料，不幫忙記回合；回合照舊由玩家在戰績畫面輸入（2026-11-19 畫地圖時決定）。依《血與刃的白薔薇》的流程，決定：

1. 主持和 `matches` 的「局」是什麼關係：一定要先在戰績開局才能開主持，還是可以不掛在任何一局上直接開。畫地圖時這一點沒有定案。
2. 每個階段主持人主動說什麼：開局說明、每個回合開始與結束、結束時宣布結果。哪些是固定台詞，哪些讓模型自由發揮。
3. 主持人靠什麼知道「該開口了」，以及這個回合「誰出了牌、翻出什麼」：讀到戰績有新的回合紀錄、玩家在頁面按鍵、玩家開口告訴它，或其他方式。已知戰績的回合紀錄要到翻牌結算後才填得出來，而且整桌都不出牌的回合目前記不進去。
4. 「現在走到哪個階段」由誰記：後端程式、Agent 框架，還是模型自己記。
5. 隱藏資訊：主持人可以知道哪些、絕對不能說出哪些。玩家要不要把自己的陣營、手牌、水晶數字告訴主持人。主持人的聲音從喇叭出來，全桌都聽得到。
6. 一局怎麼開始主持、怎麼結束；中途斷線或有人關掉頁面時怎麼辦。
7. 玩家在流程中途問規則時，主持人回答完怎麼接回流程。
8. 規則書裡沒有主持人這個角色。開局的口令與倒數原本是玩家自己喊，要不要改由主持人唸；夜晚階段主持人做什麼。
9. 主持人怎麼知道分出勝負了：誰來算死亡區與獻祭區的張數（主持人自己從回合紀錄推、玩家告訴它，或不由主持人宣布）。門檻數字來自「[對照實體遊戲，補齊白薔薇規則裡讀不到的地方](15-white-rose-rule-gaps.md)」。
10. 用詞：規則書的「回合」是全桌一起走完三個階段，`matches` 的 `turn_number` 也是這個單位；AGENTS.md §10.2 的「回合」卻是「輪到某位玩家行動的期間」。規則書把階段叫「動作」。主持人的台詞與 spec 用哪個詞，要不要向組員提議調整 §10.2。

新出現的用詞（例如每場主持、主持人說的話要叫什麼）當場寫進 `GLOSSARY.md` 的提案區。

## Answer

2026-11-20 立倫決定：

### 1. 和戰績的「局」的關係

- **一場主持不掛在戰績的任何一局上**。主持人不讀 `matches` 的局與回合紀錄。
- 開主持時只填**人數（5 到 10）**，不填名字與座位。主持人說話不用座位號碼，例如出牌階段說「從放水晶的人開始，順時針輪流」。
- 獲勝門檻與水晶格數由人數查 15 的表得出。

### 2. 開始主持

按「開始主持」後依序：

1. **開場**（固定台詞）：打招呼，說出人數、圓版格數、兩個陣營的獲勝門檻，例如「這局 7 人，圓版有 6 格；白薔薇陣營獻祭 6 張花苞獲勝，血刃陣營死亡區 4 張獲勝」。
2. **開局準備**（固定台詞）：用一段話帶過，每人拿幽魂、信者、魔法之書，抽一顆水晶不給別人看，發角色牌，金幣交給任意一位玩家。說完等玩家「下一步」。
3. **夜晚兩步**（固定台詞，用自己的話寫，不照抄規則書原句）：主持人唸睜眼互看的口令並倒數 3 秒；敲桌子讓雙刃換牌那一步，倒數 **10 秒**。
4. 夜晚結束不等「下一步」，直接說「天亮了」，進第 1 回合階段 1。

### 3. 進行中

- **換階段**：頁面「下一步」鍵，或玩家開口說「下一步」（主持人呼叫工具通知後端）。兩種都可以，按鍵當保底。
- **退回**：頁面「上一步」鍵，或說「回上一步」。退回後主持人重新說那個階段要做什麼。
- **誰記住走到哪**：後端程式記第幾回合、哪個階段、圓版放了幾顆水晶（每個回合一顆）。主持人不自己記。每次換階段，後端把最新狀況用文字告訴主持人。狀態放在 Agent 框架還是一般程式，由「[選哪個 Agent 框架、它負責什麼](10-agent-framework-choice.md)」決定。
- **每個階段開始說什麼**：後端只告訴主持人現在是哪個階段，**由主持人自由說**。討論時擬過一張「每個階段開始的第一句」固定台詞表（第 1 回合完整版、之後簡短版），**列為備案，不做**。
- **翻牌結果**：主持人**不知道**翻出什麼，不記獻祭區、死亡區的張數，不結算、不判斷勝負。玩家自己結算。
- **中途問規則**：答完補一句「回到第幾回合的哪個階段」，不重講這個階段，也不自己往下推進（07 補測時主持人被打斷後會自己推進流程，指令要明確禁止）。

### 4. 隱藏資訊

- 主持人只知道公開的事，不向玩家要陣營、手牌、水晶數字，也不記。
- 玩家自己說出私密的事（例如「我是司教」），主持人不重複、不記。
- 被問「你覺得誰是血刃」這類推理問題，主持人不分析，中立帶過。
- 被問魔法之書的效果，固定回答：「**魔法之書的效果要看書上的說明，我不能為你解釋。**」

### 5. 結束

- **圓版放滿**：後端由人數知道總格數。放最後一顆水晶的那個回合，開始時主持人提醒「這是最後一個回合」；翻牌後提醒「圓版放滿了，白薔薇陣營手上還有花朵或花苞牌的話，血刃陣營獲勝」，請玩家自己判斷。
- **提早分出勝負**：玩家說「結束了」或按「結束主持」，主持人唸結束台詞，這場主持結束。玩家有說哪一方贏就恭喜那一方，沒說就用不分陣營的版本。
- **頁面被關掉或重新整理**：後端把這場主持的狀態保留 **30 分鐘**（記憶體，不建資料表）。重開頁面可以選「接著主持（第 N 回合某階段）」或「重新開始」。
- 180 秒沒產生回答被阿里雲斷線，不在這張，屬於「[主持人怎麼撐完一局：記性上限與 180 秒斷線](17-keep-host-alive-through-a-match.md)」。

### 6. 固定台詞與自由說

- 固定台詞：開場、開局準備、夜晚兩步、最後一個回合的兩句提醒、結束台詞、魔法之書那句。由後端交給主持人照唸，字句可以略有出入。
- 自由說：每個階段開始時說的話、回答規則問題、接回流程那句、閒聊。

### 7. 用詞

- 照規則書：「**回合**」指全桌走完三個階段（和 `turn_number` 一致），「**階段**」指其中一步，不用「動作」，也不用「輪」。
- 不為了單一款遊戲的規則書向組員提議改 AGENTS.md §10.2。
- `GLOSSARY.md` 提案區新增「一場主持（hosting session）」、「固定台詞（script line）」。

### 影響

- 「[主持人能查哪些資料、誰能開主持](13-host-tools-and-permissions.md)」：第 3 題「查局況」用不到 `matches`；第 4 題不能再用「是不是這一局的參加者」判斷誰能開主持。
- 「[主持人怎麼撐完一局：記性上限與 180 秒斷線](17-keep-host-alive-through-a-match.md)」：第 4 題的「走到哪個階段」由後端記，不是前情摘要；前情摘要至少要帶第幾回合、哪個階段。
- 「[選哪個 Agent 框架、它負責什麼](10-agent-framework-choice.md)」：要決定階段狀態（第幾回合、哪個階段、放了幾顆水晶，含上一步與 30 分鐘保留）放在框架還是一般程式。
- 「[向新善、永傑、瑋鋐確認戰績欄位與規則全文的問題](16-ask-owners-about-matches-and-rules-text.md)」問到的 `matches` 三項改動，不再直接影響主持。
- 地圖的「主持人的人設與說話風格」可以開 ticket。
