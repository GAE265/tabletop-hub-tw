# 主持人在一局裡怎麼帶流程

Type: grilling
Status: open
Blocked by: 04
Map: [AI 語音主持](../map.md)

## Question

主持人以帶流程為主。首版只讀資料，不幫忙記回合；回合照舊由玩家在戰績畫面輸入（2026-11-19 畫地圖時決定）。依《血與刃的白薔薇》的流程，決定：

1. 主持和 `matches` 的「局」是什麼關係：一定要先在戰績開局才能開主持，還是可以不掛在任何一局上直接開。畫地圖時這一點沒有定案。
2. 每個階段主持人主動說什麼：開局說明、每個回合開始與結束、結束時宣布結果。哪些是固定台詞，哪些讓模型自由發揮。
3. 主持人靠什麼知道「該開口了」：讀到戰績有新的回合紀錄、玩家在頁面按鍵、玩家開口說「下一個回合」，或其他方式。
4. 「現在走到哪個階段」由誰記：後端程式、Agent 框架，還是模型自己記。
5. 隱藏資訊：主持人可以知道哪些、絕對不能說出哪些。
6. 一局怎麼開始主持、怎麼結束；中途斷線或有人關掉頁面時怎麼辦。
7. 玩家在流程中途問規則時，主持人回答完怎麼接回流程。

新出現的用詞（例如每場主持、主持人說的話要叫什麼）當場寫進 `GLOSSARY.md` 的提案區。
