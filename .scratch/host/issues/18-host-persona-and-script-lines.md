# 主持人的人設與台詞

Type: prototype
Status: open
Blocked by: 08
Map: [AI 語音主持](../map.md)

## Question

「[主持人在一局裡怎麼帶流程](08-host-flow-in-a-match.md)」定了主持人什麼時候說話、哪些話照稿唸。這張決定它**怎麼說**，寫成給即時語音模型的指令，並用真的聲音聽過（聲線 `xunanchuan_v3.1`、`longyuan_v3.1`，模型 Flash）：

1. 人設：主持人是什麼樣的角色、說話的語氣（例如沉穩的說書人、熱鬧的派對主持）。開場、夜晚、最後一個回合、結束各要什麼情緒。
2. 固定台詞的字句：開場（人數、圓版格數、兩個陣營的獲勝門檻）、開局準備、夜晚兩步（睜眼互看倒數 3 秒、敲桌子倒數 10 秒）、最後一個回合的兩句提醒、結束台詞（恭喜某一方、不分陣營兩種）。用自己的話寫，不照抄規則書。魔法之書那句已定，不改。
3. 自由說的部分要給模型什麼範圍：每個階段開始時說多長、要不要重述做法、閒聊時能不能開玩笑、多久不講話算正常。
4. 指令裡要寫的禁止事項（08 已定）：不自己推進流程、不分析誰是哪個陣營、不重複玩家說出的私密資訊、不解釋魔法之書。

試聽用的指令在 `prototypes/listen-test/index.html`，可以沿用。原型放 `.scratch/host/prototypes/`，錄音不進 repo。
