# Spec Delta

## Purpose

開團與編輯表單的店家、遊戲改成下拉選單；揪團卡片與詳細頁顯示多款遊戲。以下取代 `add-groups-calendar` 的 `groups-calendar-page` spec 中表單的店家欄位與遊戲欄位。

## MODIFIED Requirements

### Requirement: 選擇店家
開團表單的店家 SHALL 是下拉選單，選項來自 `GET /api/v1/shops`（店家名稱）。不再提供手動輸入店家 ID。編輯揪團時不能改店家（與原本相同），不顯示這個欄位。

#### Scenario: 載入店家
- **WHEN** 開啟開團表單，後端回 2 間店家
- **THEN** 下拉選單列出 2 間店家的名稱，預設沒有選取

#### Scenario: 沒選店家就送出
- **WHEN** 沒選店家就按「送出」
- **THEN** 不呼叫 API，店家欄位顯示「請選擇店家」

#### Scenario: 店家清單載入失敗
- **WHEN** `GET /api/v1/shops` 失敗
- **THEN** 店家欄位顯示錯誤訊息與「重試」，表單其他欄位仍可填寫

### Requirement: 選擇遊戲
表單的遊戲 SHALL 是可以搜尋、可以複選的下拉選單：輸入關鍵字後以 `GET /api/v1/games?q=` 搜尋（輸入停止 300 毫秒後才查詢），從結果中點選加入；已選的遊戲以標籤顯示在欄位下方，依選擇順序排列，可以按 ✕ 移除。已選的遊戲不再出現在搜尋結果中。送出時以 `game_ids` 傳給後端。編輯時帶入既有的遊戲。

#### Scenario: 搜尋並選擇
- **WHEN** 輸入「阿瓦」，從結果點選「阿瓦隆」
- **THEN** 「阿瓦隆」以標籤顯示，輸入框清空

#### Scenario: 選多款
- **WHEN** 依序選「阿瓦隆」、「馬可波羅」
- **THEN** 兩個標籤依序顯示，送出時 `game_ids` 為這兩款的編號，依選擇順序

#### Scenario: 移除已選的遊戲
- **WHEN** 按「阿瓦隆」標籤的 ✕
- **THEN** 標籤消失，送出時 `game_ids` 不含阿瓦隆

#### Scenario: 已選的遊戲不重複出現
- **WHEN** 已選「阿瓦隆」，再搜尋「阿瓦」
- **THEN** 搜尋結果不包含阿瓦隆

#### Scenario: 沒有符合的遊戲
- **WHEN** 搜尋結果為空
- **THEN** 顯示「找不到符合的遊戲」

#### Scenario: 編輯時帶入既有遊戲
- **WHEN** 編輯一個有 2 款遊戲的揪團
- **THEN** 表單顯示這 2 款遊戲的標籤

### Requirement: 顯示多款遊戲
揪團卡片與詳細頁 SHALL 顯示該揪團所有遊戲的名稱（每款一個標籤），沒有遊戲時不顯示。

#### Scenario: 卡片顯示多款遊戲
- **WHEN** 某揪團有 2 款遊戲
- **THEN** 卡片上顯示 2 個遊戲標籤
