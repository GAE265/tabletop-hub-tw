# Spec Delta

## Purpose

開團與編輯表單的店家、遊戲改成下拉選單；揪團卡片與詳細頁顯示多款遊戲。以下取代 `add-groups-calendar` 的 `groups-calendar-page` spec 中表單的店家欄位與遊戲欄位。

## MODIFIED Requirements

### Requirement: 選擇店家
開團表單的店家 SHALL 是下拉選單，選項來自 `GET /api/v1/shops`（店家名稱）。不再提供手動輸入店家 ID。編輯揪團時不能改店家（與原本相同），不顯示這個欄位。

#### Scenario: 載入店家
- **WHEN** 開啟開團表單，後端回 2 間店家
- **THEN** 下拉選單列出 2 間店家的名稱，預設沒有選取

#### Scenario: 沒選店家就送出
- **WHEN** 沒選店家就按「送出」
- **THEN** 不呼叫 API，店家欄位顯示「請選擇店家」

#### Scenario: 店家清單載入失敗
- **WHEN** `GET /api/v1/shops` 失敗
- **THEN** 店家欄位顯示錯誤訊息與「重試」，表單其他欄位仍可填寫

### Requirement: 選擇遊戲
表單的遊戲 SHALL 是可以搜尋、可以複選的下拉式選單：點欄位展開全部遊戲（`GET /api/v1/games`，一次載入全部，超過一頁時自動補齊），每款有勾選框；清單上方的搜尋框依名稱在本機篩選（部分相符、英文不分大小寫，不另外呼叫 API）。勾選的遊戲以標籤顯示在欄位下方，依勾選順序排列，可以按 ✕ 或取消勾選來移除。送出時以 `game_ids` 傳給後端。編輯時帶入既有的遊戲。

#### Scenario: 展開與收起
- **WHEN** 點遊戲欄位
- **THEN** 展開全部遊戲的清單；再點一次收起

#### Scenario: 勾選多款
- **WHEN** 依序勾選「馬可波羅」、「阿瓦隆」
- **THEN** 兩個標籤依勾選順序顯示，送出時 `game_ids` 依這個順序

#### Scenario: 搜尋篩選
- **WHEN** 在搜尋框輸入「阿」
- **THEN** 清單只剩名稱含「阿」的遊戲，不呼叫 API

#### Scenario: 移除已選的遊戲
- **WHEN** 取消勾選，或按標籤的 ✕
- **THEN** 標籤消失、勾選取消，送出時 `game_ids` 不含該遊戲

#### Scenario: 沒有符合的遊戲
- **WHEN** 篩選結果為空
- **THEN** 顯示「找不到符合的遊戲」

#### Scenario: 遊戲清單載入失敗
- **WHEN** `GET /api/v1/games` 失敗
- **THEN** 清單位置顯示錯誤與「重試」

#### Scenario: 編輯時帶入既有遊戲
- **WHEN** 編輯一個有 2 款遊戲的揪團
- **THEN** 顯示這 2 款遊戲的標籤，展開時這 2 款為已勾選

### Requirement: 顯示多款遊戲
揪團卡片與詳細頁 SHALL 顯示該揪團所有遊戲的名稱（每款一個標籤），沒有遊戲時不顯示。

#### Scenario: 卡片顯示多款遊戲
- **WHEN** 某揪團有 2 款遊戲
- **THEN** 卡片上顯示 2 個遊戲標籤
