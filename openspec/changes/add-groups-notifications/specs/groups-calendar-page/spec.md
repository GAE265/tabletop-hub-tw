# Spec Delta

## Purpose

揪團月曆與開團／編輯表單不能選今天以前的日期（使用者要求放在 add-groups-notifications 同一個 MR）。

## ADDED Requirements

### Requirement: 今天以前的日期不能選
揪團月曆中，今天（台灣時間）以前的日期格 SHALL 顯示為停用、點了沒有反應，但照樣顯示當天的團數。切換月份時，預設選取該月第一天；如果第一天已經過了且該月包含今天，改選今天。開團／編輯表單的日期選擇器 SHALL 只能選今天以後（含今天），編輯日期已過的揪團時，選擇器的初始日期為今天。

#### Scenario: 點過去的日期
- **WHEN** 今天是 11/14，點 11/13
- **THEN** 選取的日期維持不變

#### Scenario: 過去的日期照樣顯示團數
- **WHEN** 11/10 有 1 團，今天是 11/14
- **THEN** 11/10 的格子顯示「1 團」，但是停用、點不下去

#### Scenario: 已過的揪團看得出差別
- **WHEN** 11/10（已過）與 11/20 各有 1 團，今天是 11/14
- **THEN** 11/10 的格子是灰底、灰字；11/20 維持原本有揪團的顏色

#### Scenario: 今天與以後可以點
- **WHEN** 點今天或之後的日期
- **THEN** 選取該日

#### Scenario: 切回本月
- **WHEN** 從 12 月切回 11 月，今天是 11/14
- **THEN** 選取 11/14，不是 11/1

#### Scenario: 表單的日期
- **WHEN** 開啟開團或編輯表單的日期選擇器（包含編輯 11/1 的揪團）
- **THEN** 最早只能選今天，初始日期不早於今天

### Requirement: 開團入口只有一個
揪團頁的右上角 MUST NOT 有開團按鈕。選取的日期有揪團時，當天列表的最下方 SHALL 有「我要揪團」按鈕；沒有揪團時，只有空狀態裡的那一顆。按下後開啟開團表單，日期預設為選取的日期。

#### Scenario: 右上角沒有按鈕
- **WHEN** 開啟揪團頁
- **THEN** 右上角沒有開團按鈕

#### Scenario: 當天有揪團
- **WHEN** 選取的日期有揪團
- **THEN** 揪團卡片的下方有一顆「我要揪團」

#### Scenario: 當天沒有揪團
- **WHEN** 選取的日期沒有揪團
- **THEN** 只有空狀態裡的開團按鈕
