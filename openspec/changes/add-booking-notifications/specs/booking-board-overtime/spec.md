# Spec Delta

## Purpose

店家看板標示已入座、但已經超過結束時間還沒離店結帳的訂位（前端，即時計算）。

## ADDED Requirements

### Requirement: 店家看板標示超時
店家看板上，狀態為「已入座」（`seated`）且現在已超過結束時間至少 1 分鐘的訂位 SHALL 視為超時：
- 訂位卡顯示「已超時 N 分鐘」（N 為超過的整數分鐘）。
- 座位圖上該訂位的桌子用「已超時」的顏色，圖例加上「已超時」。

其他狀態（已確認、已完成、已取消、未出席），或還沒到結束時間，MUST NOT 顯示超時。看板開著時每分鐘重新計算一次（不重新查詢 API）。玩家看到的座位圖不顯示超時。

#### Scenario: 超時
- **WHEN** 已入座的訂位結束時間是 19:00，現在 19:25
- **THEN** 訂位卡顯示「已超時 25 分鐘」，座位圖上那張桌子是「已超時」的顏色

#### Scenario: 還沒到結束時間
- **WHEN** 已入座的訂位結束時間是 19:00，現在 18:50
- **THEN** 沒有超時標示

#### Scenario: 不是已入座
- **WHEN** 已確認或已完成的訂位，結束時間已過
- **THEN** 沒有超時標示

#### Scenario: 時間經過
- **WHEN** 看板開著，時間從 18:59 走到 19:01
- **THEN** 一分鐘內出現「已超時 1 分鐘」

#### Scenario: 玩家的座位圖
- **WHEN** 玩家在訂位頁看座位圖
- **THEN** 圖例沒有「已超時」
